# 信息源与核验策略

## 1. 可信度分层

| 层级 | 可用来源 | 用法 |
|---|---|---|
| Tier 1 | 官方公告、官方文档、模型卡、论文原文、监管文件、公司官方 JD、用户本人面试复盘 | 可作为主证据；来源对自身发布的事实可单源入选 |
| Tier 2 | Reuters 等大型通讯社、专业科技媒体、公开可访问的工程媒体 | 用于发现、补充背景或交叉核验；重大独家结论需第二个独立域名或原始来源 |
| Tier 3 | 聚合站、社交平台、论坛、百科、转载号 | 只作线索；不得单独支撑新闻标题、数字、发布日期或“真实面经” |

搜索结果摘要、网址标题、AI 摘要和其他日报都不是证据。必须打开最终链接。

## 2. 来源清单设计

优先覆盖五类信号：

1. 模型与产品：OpenAI、Anthropic、Google/DeepMind、Meta、Microsoft、Qwen、DeepSeek、Hugging Face、GitHub。
2. 研究：机构研究博客、arXiv 论文原文、模型卡和代码仓库发布页。
3. 政策与安全：监管机构、标准机构、漏洞公告和厂商安全说明。
4. 产业：大型通讯社和专业科技媒体，用于资本、并购、商业合作等官方不一定完整披露的事件。
5. 求职与面试：公司官方 JD、招聘页、公开工程文章，以及用户本人保存的面试复盘。

`config/sources.json` 保存可直接使用的入口。只把已验证可访问的 RSS/Atom 地址标为 `feed`；没有稳定订阅源的站点使用 `search`，不要猜测 RSS 地址。

## 3. 抓取与检索顺序

按以下回退顺序采集：

1. 官方 API 或 RSS/Atom。
2. 官方新闻索引、研究索引、发布页或招聘页。
3. 限定官方域名和日期窗口的搜索。
4. 公开、允许访问的普通 HTML。
5. 对必须渲染且公开可访问的页面使用浏览器读取。
6. 仍无法访问时放弃该条；不得绕过登录、付费墙、验证码或 robots 限制。

每次先收集 30–50 条候选，再核验和筛选。搜索式示例：

```text
site:anthropic.com/news after:2026-08-13 before:2026-08-17
site:qwenlm.github.io/blog 发布 OR release after:2026-08-13
site:reuters.com/technology/artificial-intelligence after:2026-08-13 before:2026-08-17
```

搜索日期只是发现过滤器。最终日期必须从打开后的页面、订阅元数据或原始文件读取。

## 4. 事实核验

对每条候选逐项检查：

- 标题主语、动作、对象是否都能由来源支持。
- 数字、版本号、价格、发布日期、事件日期是否明确出现。
- “发布日”和“事件发生/生效日”是否是同一天；不确定时将事件日期写为 `null`。
- `published_at` 保留原始时区；渲染时统一换算到配置时区，并在标题中明确时区。
- 链接是否指向承载该事实的具体页面，而不是首页或无关背景页。
- 重大非官方消息是否有两个独立域名，且不是互相转载同一匿名来源。
- 摘要是否为短篇中文转述，没有复制原文段落。

来源自身的营销表述要加归属，例如“OpenAI 表示……”，不要改写成无条件事实。

## 5. 去重

按以下顺序聚合同一事件：

1. 相同 `event_key`。
2. 规范化后相同的 canonical URL。
3. 标题高度相似，且发布时间相差不超过配置值。

同组优先保留 Tier 1 原始来源；把其他链接并入 `evidence_urls`，不要将同一事件的官方稿和媒体转述占用两个榜位。版本更新、价格调整和同日教程如果动作不同，不应只因出现相同模型名而合并。

## 6. 时效与重要性

默认窗口为 72 小时；明确标记 `tracking: true` 的持续事件最多保留 30 天。排序由四项加权：

- 时效：离 `as_of` 越近越高。
- 重要性：能力、价格、可用范围、政策、安全或产业结构变化的幅度。
- 可信度：Tier 1 高于 Tier 2；已交叉核验高于未核验。
- 相关性：对 AI 产品经理的产品决策、评测、成本、合规、求职或面试是否有直接价值。

不要因“需要 Top 10”降低阈值。合格条目少时明确写“本期仅有 N 条通过核验”。

## 7. 面试栏目边界

- 从新闻、论文、技术文章或 JD 推导的问题必须标为 `模拟面试题` 或 `岗位知识卡`。
- `真实面经` 必须来自明确描述真实面试过程的原始记录，并保留作者/用户提供的来源。
- 招聘页只能证明岗位职责或要求，不能证明某道题真的在面试中出现。
- 百科或概念文章可以辅助理解，不得伪装成真实面试证据。
